用 CIB 把政策组合筛成自洽情景

先把政策组合筛干净，再交给下游模型

CIB（Cross-Impact Balance，交叉影响平衡）不预测未来，只判断哪些政策组合彼此打架。 平台把政策文本翻译成描述符取值、筛出自洽的情景簇，再翻译成 GCAM-China / CHEER-CGE 能挂载的参数。 不算减排量——那是模型的活；平台保证送进模型的那套政策包，自己立得住。

三个标记什么意思

选择描述符与状态

描述符按三级组织。勾选后点名称展开，可以看到它的翻译依据与时间锚点——这一步是整个流程的核心。 每个状态右侧的数值区间是该档位的取值锚点：把「高速 / 中速」这类定性标签落到具体范围上，定性标签就变成了半定量档位。 点区间即可修改数值、重命名或增删状态——标准不必只有一套，可以换成自己的口径。 每个描述符只取一个状态（单选）：不同状态属于不同情景；要排除不可行的档位，请用下方的「数值锚定」，那里有区间依据可追溯。

数值锚定 输入条件 · 先定已知值

区间怎么参与检算
状态区间原本只是说明性标注，这里让它参与检算。给某个描述符填一个已知值或现实区间 （比如「经济增速已知在 4.5~5.0」）。它和状态选择是同一层的输入，所以放在这一页，选完状态就能顺手定。，检算时凡是区间与它完全不相交的状态都直接排除—— 这套假设在数值上就站不住，不必再拿去比对。
与下面的「情景筛选」不是一回事：锚定是检算前缩小搜索空间（会改变组合数与检验结果）， 筛选是检算后过滤展示（不改变检验结果）。锚定管"数值上行不行"，筛选管"逻辑上剩下哪些"。

跨层一致性 输入条件 · 跨层口径

跨层怎么比
同一套假设摊到国家、省、市三个尺度上，上级定的调子，下级不能反着来。 每层默认跟随你在上面选的状态，可单独改；平台只比较相邻两层——档位差 ≥2 判为方向相反。改一格立刻重算冲突，点「把下级调到相邻档」可一键修正。 这是「纵向一致性」，与上面的 CIB「横向自洽」是两回事：横向管这套假设内部打不打架，纵向管它上下说不说得通。

描述符框架 算法通用、底料本地

为什么换一套行业也能跑
这套算法不认「京津冀」——它只认一组描述符、每档区间、两两判断。所以描述符集可以整体导出/导入： 换一套行业或区域，同一套流程照跑。落地靠本地数据，通用性就靠这一层。

矛盾组合与处理建议 闭环

情景筛选

情景筛选是什么
自洽情景往往几十上百个，看不过来。给描述符指定要求取值，切到「结构」组里的情景表与情景地图，就只看命中的那一部分—— 这是用假设去反查「哪种未来更可能」的入口。筛选只影响展示，不改变检验结果本身。

逐层求解 跨层约束进入求解

逐层求解怎么把约束传下去
上面那张是算完再查：先各自求解，再比对档位差。这里是算的时候就带着上级的条件—— 区域级解出的每个情景，其取值转成下级的约束，下级与它区间不相交的状态直接不进枚举。 上级定「目标节奏（20–30%）」，下级「快速清洁化（30–40%）」根本不会被算到，而不是算出来再判它矛盾。
代价是有的：上级某个情景可能让下级完全无解。那不是程序出错，那就是结论—— 这套上级设想在下级没有对应的实现空间。

稳健性检验 判断改了结论还站得住吗

稳健性在扰动什么
一致性检验的输入是人给的 −3 到 +3。这一块把每条判断按置信度随机改动一档，重算几十轮： 出现率一直高的状态可以当成结论的骨架；单独改一档就让大批结论失效的那条判断， 就是人审该优先花力气的地方。结果不是概率，只衡量结论对判断的敏感程度。

分歧怎么裁定

影响谱

冲击分析问的是什么
问的是「如果某件事被强行实现，还剩下哪些可能」。平台逐个把每个状态钉死、重算自洽情景集， 再与基准对比：哪些可能被这条冲击打开、哪些被挤掉；整行为 0 的，说明这件事与当前判断不相容。 德国软件里这块叫 Influence profile（影响谱），这里是其中的定性版。

影响关系图

线怎么读

影响路径分析

间接传导怎么找
两个描述符之间没有直接打分，不代表它们互不影响——影响可以通过第三个描述符间接传导。 这里把「起点 → 终点」之间所有 2～3 段的传导链找出来，并按最弱环节排序： 一条链有多强，取决于它最弱的那一段。跨层传导（国家目标 → 省域结构 → 市级排放）本质就是路径问题。

主被动图

象限怎么读
给每个描述符算两个数：它对外施加的影响总和（主动和）和它承受的影响总和（被动和）。 横轴是被动和、纵轴是主动和，四个象限对应四种角色——这张图回答的是「我该动哪个描述符」。

相关性分析

φ 系数怎么读
回答「哪些状态总是绑在一起出现」。用 φ 系数衡量：＋100% 表示两者要么同时出现、 要么同时不出现；−100% 表示此消彼长。它只说明搭配关系，不说明因果—— 因果仍要看交叉影响矩阵和传导链。

这个平台怎么用

      

    

      
它做什么：把政策组合筛成不互相打架的情景，再翻译成 GCAM-China / CHEER 能用的参数。它不算减排量，那是下游模型的活。

      
七步：选尺度 → 映射政策 → 定状态 → 定校验方式 → 两两打分 → 选目标模型 → 检验与导出。左侧竖排就是这七步，随时可跳。

      
最常用的一步：第 5 步的两两打分。每格填 −3…+3，表示「一行取这个状态，会促进还是抑制一列」。填完自动筛出没有内部矛盾的情景簇。

      
拿不准的地方：文字带虚线下划线的，鼠标放上去有解释。

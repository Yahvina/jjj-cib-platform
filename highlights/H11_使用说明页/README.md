# H11 ｜ 使用说明页：五区八节，侧栏标出读到哪

## 解决什么问题

说明不摊在操作面上，集中在同一页里，按 EPS 的结构切成五区八节——简介、使用手册（七步流程）、算法说明（判定与算法／跨层与锚定／导出与模型）、案例、参考（术语对照、版本与讨论日志）。侧栏在滚动时标出当前读到哪一节：进页时缓存八个标题的文档位置，滚动只比「谁越过了判定线」，不用 IntersectionObserver——它的 rootMargin 下边距只能靠百分比起算，视口高度不够时会一条都不触发。第三区叫「算法说明」不叫「方法学」：该区只讲平台怎么算，而真正的方法学要回答「关系依据什么判定、高低分段从哪来、由谁验证」，那三条在评分规则定稿前不写。

# H10 ｜ 九个工具收进一个工作台（正文只留结论）

## 解决什么问题

第 7 步一度是 9 张卡加两个抽屉：结论、可靠性四张、工具箱三块、筛选与矛盾，读结果的人要在这些之间滚很久。现在正文只留 5 张卡（检验结果一句话、情景地图、导出、报告、配置摘要），其余九件收进一个近全屏的工作台弹窗——左栏九个 tab 按三组分（深挖／可靠性／工具箱），右侧内容，每块顶上留一句「怎么读这张图」的常驻说明。工程上最省风险的一步是：九个容器的 id 原样保留、弹窗 DOM 常驻（关着只是 display:none），八个渲染函数一行没改。

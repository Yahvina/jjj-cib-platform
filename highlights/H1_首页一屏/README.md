# H1 ｜ 首页：一屏讲清定位

## 解决什么问题

第一页要先讲清对方的问题，再讲自己做了什么。这一屏用一张交叉影响矩阵的结构示意图＋四个实时统计（描述符／政策路径／状态／组合数）代替空泛介绍，下方三段流程只说三件事：界定变量、两两判定、求取自洽情景。统计数字全部由 homeStatData() 现算，没有一个写死的估值——v1.2 之前首页那三个数字是估算的，已经删掉了。

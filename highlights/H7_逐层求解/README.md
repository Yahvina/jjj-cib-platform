# H7 ｜ 逐层求解（下沉为折叠段）

## 解决什么问题

让跨层约束真正进入求解，而不只是事后比对。上级解出的每个自洽情景，其取值转成下级的约束：下级与它区间不相交的状态根本进不了枚举。上级定「目标节奏20–30%」，下级「快速清洁化 30–40%」就不会被算到。上级某情景若让下级完全无解，会单独计数——那不是程序出错，那就是结论。v1.5 把它的入口从常驻卡片改成默认收起的折叠段：不勾多层时整段不出现，能力一点没少。组合是否自洽只取决于组合自身，所以整层只判一次（25 万次预算，小空间精确、大空间固定种子抽样），再按各组允许集归桶筛选。

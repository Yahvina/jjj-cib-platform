# H3 ｜ 各层差异预览与跨层约束前置

## 解决什么问题

多尺度在界面上的落点。先把「同一套描述符在国家级／区域级／省级／市级口径不一样」摊开成一张表，再把跨层核对从「算完回头比」改成「选上层档位就立刻筛下层」：与上层方向相差 ≥2 档、或取值区间不相交的下层档位直接置灰，原因写在选项里。平台不替用户改档——档位冲突可能是真实的政策张力，上层改动后下层原选若不相容，只清空并说明原因，由用户重选。

## 复用方式

1. 引入 `../_shared/base.css`（含 v1.5 全部设计令牌与基础组件）；
2. 把 `fragment.html` 粘进页面结构；
3. 引入 `logic.js`，在数据准备好之后调用其渲染入口。

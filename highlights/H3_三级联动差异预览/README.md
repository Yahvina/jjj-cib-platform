# H3 ｜ 三层差异预览与跨层约束

## 解决什么问题

对应导师提出的「多尺度」要求。勾选层级后自动生成同一套描述符在三级上的取值与约束关系，并提示三类跨层约束（分解汇总／口径一致／边界）。

## 代码位置（原 index.html）

- HTML：第 247–267 行、第 269–285 行
- 逻辑：第 556–561 行、第 628–649 行
- 样式：见本目录 `style.css`；完整设计令牌见 `../_shared/base.css`

## 本目录文件

| 文件 | 内容 |
|---|---|
| `fragment.html` | 该模块的 HTML 片段 |

## 复用方式

1. 把 `../_shared/base.css` 引入页面；
2. 复制 `fragment.html` 到页面结构里；
3. 引入 `logic.js`，并在页面加载后调用模块的渲染入口。

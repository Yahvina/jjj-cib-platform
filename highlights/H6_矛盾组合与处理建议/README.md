# H6 ｜ 矛盾组合与处理建议（闭环）

## 解决什么问题

不只报矛盾，还要说清「为什么矛盾」「改成什么就不矛盾」「采纳后重跑」。v1.5 起不再只看用户选中的那几个档位，而是过所有描述符对，列出全部互斥对（上限 40 对，超出会标注已截断），另单列「孤立档位」。两者不同义：孤立档位是它自己站不住（任何自洽情景里都没出现），互斥对是两档各自都行、凑一起不行。建议是算出来的——从自洽集里找与其中一边共存过的另一档，点一下就真的改状态并重跑。
